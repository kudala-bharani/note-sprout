Local model setup

NoteSprout uses Ollama on this computer. No account or API key needed.

From the NoteSprout project folder, run npm run ai in a terminal. In another terminal, run npm run model:pull. Then check the connection above. On a new computer, install Ollama first; see the README.

The first model download needs internet; creating study cards stays on this computer. You can try the handwritten sample while you set up.
